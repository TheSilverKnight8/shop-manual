# shop-manual
A virtual shop manual for the various tools and machines at our school engineering workshop. 

Link: https://thesilverknight8.github.io/shop-manual/

Use the Tool Picker to find the right tool for your project, entering all of the fields for the whole piece.
The Tool Picker will direct you to the appropriate tool based on your specifications.
Tool entries cover the necessary information for operation.
Use the Tool Directory to browse all of the tools in the shop.


All files coded in VS code with JavaScript, HTML, and CSS; hosted on GitHub Pages.
The picker works by filtering tools based on their defined parameters. To prevent excessive dead ends, objectives that do not have a tool paired with the selected material are removed from the list. All tool data is on one file (data/tools.js) and the tool page (tool.html) loads whichever data was selected.

All tool entries are written to ASD-STE100 (Simplified Technical English) standards for efficient instruction.
