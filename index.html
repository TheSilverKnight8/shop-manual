How to use this manual

  1. Use the Tool Picker to find the right tool for your project, entering all of the fields for the whole piece.
  2. The Tool Picker will direct you to the appropriate tool based on your specifications.
  3. Tool entries cover the necessary information for operation.
  4. Use the Tool Directory to browse all of the tools in the shop.
