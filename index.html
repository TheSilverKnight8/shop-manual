How to use this manual

  1. Use the Tool Picker to find a tool. Enter the size of the whole piece.
  2. The Tool Picker shows the tools that fit your choices. Select a tool to open its entry.
  3. Each tool entry has safety information and operation steps. Read it before you use the tool.
  4. Use the Tool Directory to see all the tools in the shop.
